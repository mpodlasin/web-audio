# Step 1

Hello!

Welcome to the first chapter of the `AudioCanvas` tutorial!

In this chapter, we will learn how to create nodes in `AudioCanvas` and connect them to build a simple sound source that plays a melody.

Before you begin, remember that you can get help and give feedback on the official [AudioCanvas Discord Server]()! If something is unclear or you get stuck at any point, feel free to reach out there.

Click the `Next` button to get started!

Now that the <Clr nodeType="sine-oscillator">Sine</Clr> oscillator is connected to the <Clr nodeType="destination">Output</Clr> node, an audio signal can flow between them.

All nodes in `AudioCanvas` have signal inputs and/or outputs, depending on their function.

Inputs are always on the left side of a node, as is the case for the <Clr nodeType="destination">Output</Clr> node.

Outputs are always on the right side, as is the case for the <Clr nodeType="sine-oscillator">Sine</Clr> node.

As you’ve heard, by controlling the frequency, we can control what we would call the "pitch" of the sound.

Indeed, by properly changing the frequency over time, we can play actual melodies.

But we don’t want to do this by hand (or rather, "by mouse"), as that would be both difficult and tiring.

Instead, we can use a <Clr nodeType="sequencer">Sequencer</Clr> node, which will do it for us.

Create a <Clr nodeType="sequencer">Sequencer</Clr> node - it can be found in the <Clr nodeType="sequencer">Pitch</Clr> section of the node creation menu.

The <Clr nodeType="sequencer">Sequencer</Clr> node might look scary, but it actually works in a simple way.

Each knob represents a frequency at a given moment, which we call a _step_.

When the <Clr nodeType="sequencer">Sequencer</Clr> is running, the emitted frequency changes from step to step - starting from step 1, finishing at step 8, and then restarting from the beginning.

By default, all frequency knobs are set to 440 hertz.

But we don't want the same frequency at each step - this would be boring, as it would result in hearing the same pitch constantly, which we experienced already.

To change that, set each frequency knob on the <Clr nodeType="sequencer">Sequencer</Clr> node to a value different from the default 440Hz - it can be any value you wish.

Notice that the <Clr nodeType="sequencer">Sequencer</Clr> node has an output on the bottom right - that's where our sequence will come from.

However, the <Clr nodeType="sine-oscillator">Sine</Clr> node does not have any inputs, so how can we control its frequency?

The <Clr nodeType="sequencer">Sequencer</Clr> node is now connected to the frequency knob of the <Clr nodeType="sine-oscillator">Sine</Clr> node.

From now on, instead of saying "knob", we will use the term _parameter_ of a node.

For example, the <Clr nodeType="sine-oscillator">Sine</Clr> node has two parameters - a frequency parameter and a detune parameter.

The <Clr nodeType="destination">Output</Clr> node has only one parameter - volume.

Meanwhile, the <Clr nodeType="sequencer">Sequencer</Clr> node has 8 parameters.

You need to be aware that when connecting a node output to a parameter, the output signal is _added_ to the value set by the parameter knob.

This means that if we want to use values _only_ from the sequencer, we should reduce the value on the frequency knob of the <Clr nodeType="sine-oscillator">Sine</Clr> node to 0 Hz.

Drag the frequency knob on the <Clr nodeType="sine-oscillator">Sine</Clr> node down until it points to 0, just as you would with a regular, unconnected knob.

But we need one more thing.

The <Clr nodeType="sequencer">Sequencer</Clr> node will not play by itself.

It requires something to tell it (via its input) how fast it should go from one step to another – a source of tempo.

The <Clr nodeType="clock">Clock</Clr> node serves exactly that purpose. You will find it in the <Clr nodeType="clock">Clock</Clr> section.

Create a <Clr nodeType="clock">Clock</Clr> node and connect it to the input of the <Clr nodeType="sequencer">Sequencer</Clr> node.

Feel free to play more with all the parameters that you see on the screen.

In the meantime let's recap the most important things we've learned so far:

- In `AudioCanvas` we create `nodes` and connect them together with `lines` in order to built synthesisers.
- Nodes have `inputs` (on the bottom lefft) and `outputs` (on the bottom right) that look like little circles.
- Nodes have also `parameters` in the form of `knobs`, which values can be changed with the mouse.
- Not only we can control parameters manually, but we can also control them with other nodes by connecting a node and a knob with a line.

The <Clr nodeType="spectrum">Spectrum</Clr> node can actually detect multiple frequencies at once.

To see that, create another <Clr nodeType="sine-oscillator">Sine Oscillator</Clr> and connect it directly to the <Clr nodeType="spectrum">Spectrum</Clr>.

_(No <Clr nodeType="gain">Gain</Clr> node is needed in this case.)_

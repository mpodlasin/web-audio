The easiest way to visualize what is happening under the hood of `AudioCanvas` is with the two following nodes:

`Number` node which simply emits a number that is set on its knob. You can find `Number` node in `Math` section.

`Value` node which displays whatever signal is being sent to it via its input. You can find `Value` node in `Visualisation` section.

Create both of those nodes and connect them together.

In other words, the <Clr nodeType="sine-oscillator">Sine Oscillator</Clr> takes exactly `1` second to:

- Begin at `1`.
- Drop to `0`.
- Return to `1`.

Once this _cycle_ is complete, the <Clr nodeType="sine-oscillator">Sine Oscillator</Clr> starts over, repeating indefinitely.

Such repetitive, periodic change is called an _oscillation_ - hence the name oscillator.

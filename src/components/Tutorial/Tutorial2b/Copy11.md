It is now much easier to see what is going on.

Look at the `Value` node first.

You can see that the number displayed there moves gradually between -1 and 1.

This is further confirmed by the `Oscilloscope` which graphs how this change occurs.

Note that when the number displayed in the `Value` node is 1, the rightmost edge of the graph in the `Oscilloscope` node is at the top of the window.

When `Value` says -1 on the other hand, rightmost edge of the graph is at the bottom of the window.

`Sequencer` node might look scary, but it actually works in a simple manner.

Each knob represents a frequency at a given moment. We call that moment a _step_. 

So, when `Sequencer` is running, emitted frequency will change from step to step. Note that we have 8 steps.

By default all frequency knobs are set to 440Hz.

But we don't want the same frequency at each step - this would be boring, as it would result in hearing the same frequency constantly, which we experienced already.

In order to change that, set each frequency knob on the `Sequencer` node to a value different than default 440Hz - it can be any value you wish.

Let's make all knobs have different values from eachother - this way it will be easier for you to hear what is going on.

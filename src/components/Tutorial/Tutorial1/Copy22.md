A frequency signal flows now via the <Clr nodeType="pitch-quantizer">Pitch Quantizer</Clr> which adjusts each incoming frequency to fit the notes that we will choose.

If you know musical scales, you can choose whatever notes you prefer.

If you do not, we recommend choosing any notes that _do not_ end with the # sign - for example `A`, `C` and `E`.

Choose 3 or more notes on the <Clr nodeType="pitch-quantizer">Pitch Quantizer</Clr> - do it while the play button is on, to hear how each chosen note changes what is being played.

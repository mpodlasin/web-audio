This is a sine wave oscillator.

It is a sound source that generates a pure sine wave.

We will explain what exactly that means in later tutorials, but for now let's just hear how it sounds.

In order to do that, we need to route audio signal to your headphones or speakers.

A node responsible for that is called <Clr nodeType="destination">Output</Clr>. You can find it in <Clr nodeType="destination">I/O</Clr> section of the node creation menu.
